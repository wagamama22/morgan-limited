## Engineering focus

This project reflects the way I approach frontend project: break a website into clear pages and reusable visual components, connect controls to useful interactions, and validate user input before presenting a result. It is a foundation for continued growth in accessibility, maintainable JavaScript, testing, and production-ready application development.

## Scope

This is a frontend demonstration. The order calculator displays a summary in the browser; it does not accept payments or save orders to a server. The contact form is not connected to a production messaging service.

## Run locally

This is a static frontend project and does not require a package installation or build step.

1. Clone or download this repository.
2. Open `index.html` in a browser, or serve the folder with a local static web server.
3. Use the navigation to open the Gallery and Contact pages.
